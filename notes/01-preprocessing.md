# 머리말

우리는 보통 딥러닝을 공부할 때 이미지 데이터를 우선적으로 배우게 됩니다. 이미지 데이터는 형태 자체가 정수형으로 이루어져 있어, 딥러닝 혹은 머신러닝 모델에 입력할 때 별도의 어려움 없이 입력할 수 있습니다. 하지만 우리가 사용하는 자연어를 생각하면 모델에 어떻게 입력해야 하는지 의문이 생깁니다. `"Hello World!"`를 어떻게 딥러닝 모델에 입력할까요?

이미지와 자연어의 차이는 두 가지입니다. 첫째, **이미지에는 픽셀이라는 최소 단위가 이미 정해져 있지만 자연어에는 없습니다.** `"Hello World!"`를 `Hello / World / !`로 자를지 `He / llo / Wor / ld / !`로 자를지는 데이터가 아니라 설계자가 정합니다. 둘째, **이미지는 크기가 달라도 리사이즈로 맞출 수 있지만 문장에는 길이를 줄이는 연산이 없습니다.** 단어를 절반으로 자를 수는 없기 때문입니다.

이번 글에서는 **GPT-2를 기준으로** `"Hello World!"`라는 문자열이 전처리를 거쳐 임베딩 벡터가 되기까지의 다섯 단계를 따라가 보겠습니다.
